# Arreglos de Notelisa

Arreglos sencillos para piano (mano derecha con la melodía, mano izquierda con notas largas) de
melodías populares y villancicos de dominio público. Están en `public/library/libre/` y en
`FUENTES.md`. Los arreglos se ceden al dominio público (CC0).

Para cambiar uno, edita su `.ly` y vuelve a generar el MusicXML con las herramientas de
`tools/mutopia/` (pasos 2 y 3 de su README), añadiendo `--arranger Notelisa`.
